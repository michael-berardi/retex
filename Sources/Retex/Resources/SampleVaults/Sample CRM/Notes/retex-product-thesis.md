# Retex product thesis

Retex is a local workspace for client operations and agent knowledge. It combines documents, a first-class Markdown Kanban, and agent activity without turning setup into a second job.

## Product rules

- Markdown files remain authoritative.
- The interface ships with strong defaults.
- Agents and people use the same records.
- Network access stays optional and visible.
- Every cache is replaceable. The vault is not.
